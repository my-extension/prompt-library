Privacy Policy

Last Updated: April 20, 2026

This Privacy Policy explains how Prompt Library ("we", "our", "us") handles user data.

Data Collection

We do not collect, store, or transmit personal data to external servers.

Local Storage

All data (such as saved prompts and settings) is stored locally in your browser using Chrome storage. This data is not shared with us or any third parties.

User Actions

The extension may interact with system features only in response to user actions. For example, prompts can be copied to the clipboard when the user explicitly chooses to do so.

External Resources

The extension may open external web pages (such as a welcome page) in the browser. These pages are not used to collect or process user data from the extension.

Third Parties

We do not sell, share, or transfer personal data to third parties.

Remote Code

All extension code is packaged and runs locally. No remote code is executed.

Changes

We may update this Privacy Policy if the extension functionality changes.
